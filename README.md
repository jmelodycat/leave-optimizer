# 휴가 최적화 계산기

공휴일을 최대한 활용하는 휴가 계획을 세워주는 웹 서비스입니다.

- 연도/월별 달력 탐색
- 휴가 일수 설정 → 최적 휴가 조합 자동 추천
- 달력 날짜 클릭 → 해당 날 기준 최적 계획 즉시 계산
- 공휴일 정보: 한국천문연구원 (data.go.kr)

## 개발

```bash
npm install
npm run dev
```

## 배포 (Vercel)

환경변수 `DATA_GO_KR_API_KEY`에 data.go.kr API 키를 설정하면 실시간 공휴일 데이터를 사용합니다.
API 키 없이도 내장 데이터(2026~2028)로 동작합니다.
